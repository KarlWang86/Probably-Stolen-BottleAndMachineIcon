# 容器与机器图标 0.1.0

0.1.0 首次独立发布：图标实现已接入，已通过编译与原生扫描，尚待游戏内验收。

按容器实际原浆/提取物显示咖啡豆、梦帽菇和梦魇帽菇：容器中心纵排，机器本体左上横排，操作窗口容器槽同样覆盖，不显示溶剂或试剂图标。梦帽菇也覆盖 nomore 成分。实际瓶图与拖影的显隐、透明度同步。

空蒸发器只读化学助手已有记忆标签：咖啡丸对应咖啡豆、梦尘或粉色替代注射器对应梦帽菇、梦魇尘对应梦魇帽菇。没有标签时，空蒸发器不显示原料标记；仅有溶剂的瓶子不使用记忆标记。不会创建、更新或清除设备分工标签。

本模组无需化学助手。原化学助手目前仍带图标，启用本模组前须停用或移除旧绘制，避免重复。模组禁用、退出店铺或切档时清理本模组节点。

显示只读，不加工、耗料、补瓶、写入存档或修改原生形状。当前无独立工坊条目。将安装包内 BottleAndMachineIcon 文件夹放入游戏 Mods 目录，确认旧助手的同类绘制已停用后再启用本模组。
